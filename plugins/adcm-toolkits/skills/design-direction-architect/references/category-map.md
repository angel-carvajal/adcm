## Composing the Pinterest query

`<business seed> + <style name> + <artifact>`

Example: `"food truck branding website" + "dark luxury" + "landing page"`.
Then apply chips **if they render** — see `source-pinterest.md`. Run **2–3 distinct queries**, not
one query paged deeper; different phrasings surface different corpora.

## Composing the 21st.dev query

21st.dev is component-level, so query the **section**, not the business:
"pricing table", "product card", "multi-step form", "testimonial carousel".
Business type only filters the style adjective: "dark pricing table".
